# Frontend: To-Do List

Aplicação Angular 22 com Angular Material. As instruções completas (Docker, testes e arquitetura) estão no [README da raiz](../README.md).

```bash
npm ci
npx ng serve                 # http://localhost:4200 (espera a API em http://localhost:8080)
npx ng test --watch=false    # testes (Vitest)
npx ng build                 # build de produção em dist/frontend/browser
```
